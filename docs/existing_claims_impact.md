# 위고비 시장 확산에 따른 기존 담보 보험금 현가 변화

이 모형은 동일한 **SELECT 유사·비당뇨·위고비 미사용 고위험 가상 가입자 1,000명**에서 위고비 시장이 저확산에서 고확산으로 이동할 때 기존 담보의 기대 보험금 현가가 어떻게 달라지는지 비교한다. 약제비 특약 보험료, 기존 계약 보험료, 준비금, 투자손익과 자본비용은 포함하지 않는다.

## 실행

저장소 루트에서 다음을 실행한다.

```bash
python -m models.impact.existing_claims
python -m unittest tests.test_existing_claims_impact -v
```

입력은 `config/existing_claims_impact.json`, 결과는 Git 제외 경로인 `outputs/existing_claims_impact/`에 저장된다. 04번 노트북은 같은 모듈을 호출하고 결과표와 그림을 포함한다.

## 공통 계산 규칙

- 관찰기간 10년, 할인율 연 2.75%, 해지율 0, 담보 보유율 기준 100%다.
- `existing_market_low`, `existing_market_high`는 기존 시작률 모형을 다시 실행해 만든 특약 없음 전용 경로다. 선택비는 1.0이고, 0.5·1.0·1.5배 상대 시작률도 각각 재생성한다.
- 최초 시작은 생존·미시작자에게 한 번만 적용한다. 재개는 치료 상태전이 엔진에서 처리하며 신규 시작으로 세지 않는다.
- 효과기간 시계는 최초 시작일부터 최대 3년이며 재개할 때 초기화하지 않는다.
- 심근경색, 뇌졸중, 담낭절제술은 담보별 미청구/지급완료 상태를 따로 추적한다. 한 사람은 서로 다른 담보를 받을 수 있지만 동일 담보는 첫 1회만 지급한다.
- 비치명적 사건자는 생존·사망 위험과 다른 담보 위험에 남고, 미시작자이면 이후 치료를 시작할 수 있다. 사건 후 사망위험 가산은 두지 않는다.
- 일별 처리 순서는 `최초 시작 → 치료 지속·중단·재개 → 심근경색 → 뇌졸중 → 담석증·담낭절제술 → 사망 → 다음 날·할인`이다. 같은 날 비치명적 사건과 사망이 순차적으로 함께 계산될 수 있다.
- 변화의 부호는 모든 담보에서 `claim_change = PV_high − PV_low`다. 양수는 고확산에서 보험금 증가, 음수는 감소이며, `insurer_impact = −Σ claim_change`다.

모형은 개인별 몬테카를로가 아니라 일별 기대상태 모형이다. 치료 시작 코호트와 담보별 미청구 코호트를 합성곱으로 연결하며, 서로 다른 비치명적 지급이력은 주변 기대상태로 각각 추적한다.

## 담보 근거와 적용

| 담보 | 기초위험 | 치료효과 | 급부 |
|---|---:|---:|---:|
| 정기 사망 | SELECT 위약군 458 / 29,112인년 | HR 0.81 (0.71~0.93) | 1억 원 |
| 비치명적 심근경색 | 322 / 29,112인년 | HR 0.72 (0.61~0.85) | 1,000만 원 |
| 비치명적 뇌졸중 | 165 / 29,112인년 | HR 0.93 (0.74~1.15) | 1,000만 원 |
| 담낭절제술 | SELECT 담석증 위약 1.1% / 39.8개월 | SELECT 치료군 1.4%에 대응하는 위험강도비 | 1,000만 원 |

사망 HR은 위계검정상 탐색적이고, 심근경색·뇌졸중은 다중검정 미조정 보조평가변수다. 근거는 [SELECT 본 논문](https://doi.org/10.1056/NEJMoa2307563)과 저장소의 01·02번 개별 노트북을 따른다. 담석증 후 담낭절제술 전환율은 국내 관찰값 `2,706 / 13,069 = 20.7%`를 사용한다([Scientific Reports 2023](https://doi.org/10.1038/s41598-023-33440-4)). Safwan의 RR 2.59(1.40~4.82)는 기준이 아니라 SELECT 위약군 기초위험에 적용하는 불리 민감도다([Safwan et al. 2025](https://doi.org/10.5144/0256-4947.2025.129)).

## 효과 노출 방식

| ID | 처리 |
|---|---|
| `on_treatment_published` | 최초 시작 후 3년 이내 실제 치료 중 날짜에만 보고 HR/RR 적용 |
| `on_treatment_adjusted` | `exp(log(HR_ITT)/(34.2/39.8))`로 투약 중 배수를 보정해 치료 중 날짜에 적용 |
| `itt_window` | 최초 시작 후 3년 동안 중단 여부와 관계없이 보고 HR/RR 적용 |

기준 방식은 ITT 효과를 실제 치료 중 날짜에만 적용하므로 임상효과를 이중으로 약화할 수 있다. 보정형 배수도 직접 관찰된 투약 중 효과가 아니다.

## 개별 노트북과의 재현 대조

01~03번은 서로 다른 질문과 시간축으로 작성되어 값들을 그대로 더할 수 없다. `legacy_notebook_reference_comparison.csv`는 기존 출력값과 공통모형 값을 나란히 보존한다.

| 담보 | 개별 노트북 변화 | 공통모형 기준 변화 | 주된 차이 |
|---|---:|---:|---|
| 사망 | -96,961,864원 | 약 -43,571,696원 | 월 1%·3% 시작률, 3% 할인, 중단·재개 미반영 ↔ 전용 일별 시작·치료경로 |
| 심근경색 | -9,706,245원 | 약 -4,169,987원 | 개별 월 시작·노출 정의와 3% 할인 |
| 뇌졸중 | -1,302,874원 | 약 -477,162원 | 개별 월 시작·노출 정의와 3% 할인 |
| 담낭절제술 | +6,119,385원 | 약 +309,106원 | Safwan RR 2.59 기준 ↔ SELECT 1.4% 대 1.1% 기준 |

따라서 차이는 강제 보정하지 않는다. 공통모형은 대상, 시작경로, 치료노출, 생존, 할인율과 지급이력을 하나의 일별 체계로 맞춘 결과다.

## 민감도와 출력

일원 민감도는 HR/RR, 효과기간 1·3·5년, 수술 전환율, 세 노출방식, 상대 시작률, 할인율, 담보별 보유율과 기초위험 배수를 포함한다. 5년 효과는 SELECT 추적기간을 넘는 외삽이다. 결합 시나리오 `favorable`, `base`, `adverse`, `no_effect`에는 발생확률을 부여하지 않으므로 흑자확률이나 경험분포로 해석하지 않는다.

주요 출력은 다음과 같다.

- `base_claim_pv_results.csv`: 담보별 저·고확산 사건수, 보험금 PV, 변화와 보험사 영향
- `base_exposure_summary.csv`: 최초 시작자, 치료 중 인년과 생존 검증
- `base_additional_metrics.csv`: 1,000명·계약 1건당 변화와 담낭수술 상쇄 비율
- `one_way_sensitivity.csv`, `holding_rate_sensitivity.csv`: 일원 민감도
- `combined_scenarios.csv`: 결합 시나리오
- `legacy_notebook_reference_comparison.csv`: 개별 분석과 공통모형 대조
- `validation.json`: 자동 검증 결과

## 한계와 다음 연결

시작률, 담보 보유율과 효과기간은 연구 가정이며 실제 포트폴리오 추정치가 아니다. SELECT 평균위험을 10년 동안 일정하게 외삽하고, 연령 증가·사건 후 사망위험 증가·수술 대기·해지·준비금·세금·투자손익·자본비용을 반영하지 않는다. 같은 날 사건과 사망을 허용하는 순차 처리 및 주변 기대상태 추적도 단순화다.

향후 약제비 특약 손익과 연결할 때에는 시장 저·고확산 결과 전체를 특약에 귀속하지 않는다. 특약 없음 `A`와 특약 있음 `A+B`의 추가 시작경로로 기존 담보 변화분을 다시 산출한 뒤, 담보별 실제 보유·유효 비중을 적용해야 한다.
