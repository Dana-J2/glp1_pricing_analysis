# MVP 8개 상품조건 선정

## 범위

MVP 비교군은 조제당 지급액 10만·15만 원, 최대 지급횟수 6·13회, 대기기간 30·90일의 조합 8개다. `decision_horizon_units`는 모든 조건에서 13회로 유지한다. 주 분석 목표이익률은 10%, 보조 비교는 5%이며 기존 0% 보험료는 회귀검증에만 사용한다.

이 8개는 수리적으로 유일한 최적안이 아니다. 전체 27개 조건에서 극단적인 보장과 장기 지급위험을 제외한 **1차 MVP 비교군**이다.

## 제외 논리

- **20만 원:** 13회 이상과 결합하면 지원반응 증가 시 손실이 크게 확대되어 첫 MVP에서는 제외한다. `20만 원×6회`가 열위라는 뜻은 아니며 후속 고지원형 후보로 남긴다.
- **26회:** 13회보다 시작률 증가는 없지만 보험료와 장기 지급위험이 커지고 치료행태 복합 스트레스에서 손실이 발생한다.
- **180일:** 90일보다 보장을 90일 더 늦추지만 월보험료 절감은 대부분 수십 원에 그친다.

## 팀원 27개 표 검증과 재현

2026-11-18 작성된 다음 원본 두 파일을 읽어 검증했다.

- `WEGOFIT_27개_상품조건_보험료_혜택_요약_20261118.csv`
- `WEGOFIT_27개_상품조건_목표10pct_주요스트레스_NPV_20261118.csv`

두 파일은 각각 지급액 3개×한도 3개×대기기간 3개의 27개 고유 조건이며 중복·결측·누락이 없다. 기존 저장소의 90일 9개 가격·혜택·스트레스와 일치했고, 현재 엔진으로 다시 계산한 MVP 8개도 표시 정밀도 내에서 모두 일치했다. 원본 전체를 저장소에 복사하지 않고 SHA-256과 검증 결과를 `reports/mvp_issue_age_validation.json`에 남겼다.

## 실행 및 결과

```bash
python -m models.rider.mvp_age_analysis
```

- 설정: `config/mvp_product_options.json`
- 추적 결과: `data/derived/mvp_product_options_summary.csv`
- 검증: `reports/mvp_issue_age_validation.json`

원본 팀원 CSV가 Downloads에 없으면 `--team-pricing-csv`, `--team-stress-csv`로 경로를 지정한다. 팀원 원본 대조 없이 현재 엔진 결과만 다시 만들 때에는 `--skip-team-source-validation`을 명시한다.

시작률과 치료행태 스트레스는 각각 별도로 적용했으며 6×13 교차 스트레스는 계산하지 않았다. 보험료 자체의 행동 반응, 세금, 자본비용과 별도 투자손익은 포함하지 않는다.
