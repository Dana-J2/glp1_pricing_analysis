# 약제비 특약과 기존 보험금 변화의 보험사 종합영향

이 분석은 WE GO FIT 약제비 특약의 기대손익 NPV와, 특약 지원 때문에 추가로 위고비를 시작한 가입자에서 발생하는 기존 보험금 변화를 결합한다. 시장 저확산에서 고확산으로 이동하는 효과와 달리, 최종 비교는 같은 기준시장의 **특약 없음 `A`와 특약 있음 `A+B`**다.

```text
담보별 보험금 변화 = 특약 있음 기존 보험금 PV - 특약 없음 기존 보험금 PV
기존 보험금 절감액 = -Σ(담보별 보험금 변화 × 담보 보유율 × 가입금액 배수)
보험사 종합영향 = 약제비 특약 NPV + 기존 보험금 절감액
```

## 실행

```bash
python -m models.impact.insurer_total_impact
jupyter nbconvert --to notebook --execute --inplace notebooks/impact/05_위고비_보험사_종합영향.ipynb
```

입력은 `config/insurer_total_impact.json`, 결과는 Git 제외 경로인 `outputs/insurer_total_impact/`에 저장한다. 보험료를 다시 산출하지 않고 `outputs/mvp_issue_age_analysis/run_summary.json`에 저장된 목표이익률 10% 원 단위 확정 보험료를 사용한다.

## 공통 분석집단

- 대표 가입연령 62세, 남성 72%·여성 28%, 최초 계약 1,000건, 보험기간 10년
- 특약 현금흐름은 남녀별로 계산한 뒤 72:28로 가중
- 기존 보험금은 상품별로 다시 만든 동일한 `A`·`A+B` 최초 시작경로와 공통 지속·중단·재개 경로를 사용
- 임상 사건위험은 기존 공통모형의 SELECT 전체 집계 위험을 적용

따라서 결과는 실제 보험사 포트폴리오의 확정값이 아니라 **SELECT 유사 임상위험을 적용한 연구용 종합영향 시나리오**다. 현재 판매보험료의 회귀검증 기준인 49세 여성 결과와 기존 보험금 결과를 조용히 합산하지 않는다.

## 보유율 시나리오

| 담보 | 낮음 | 기준 | 높음 |
|---|---:|---:|---:|
| 사망보장 | 15.0% | 21.4% | 30.6% |
| 심근경색 | 30.0% | 40.0% | 50.0% |
| 뇌졸중 | 30.0% | 40.0% | 50.0% |
| 담낭절제술 수술 | 20.0% | 25.0% | 40.0% |

사망보장 비율은 [보험연구원 2018 보험소비자 설문조사](https://www.kiri.or.kr/pdf/연구자료/연구보고서/nre2018-12_02.pdf)의 60대 이상·전체·50대 사망보험 개인 가입률을 사용했다. 심장·뇌·질병수술 담보 범위는 [금융데이터 활용지원 플랫폼의 한화손해보험 고객유형별 장기보험 담보 가입현황](https://www.findatamall.or.kr/market/dataProdDetail?gdsSn=2402&menuNo=28) 공개 표본을 단순화한 연구 가정이다.

이는 실제 특정 보험사의 보유율을 추정한 것이 아니라, 공식 생명보험 가입률과 실제 보험사 공개 담보자료의 관찰범위 안에서 만든 공개자료 기반 대리 포트폴리오 시나리오다.

## 대표 상품 결과

대표 상품은 조제당 10만 원·통산 13회·대기기간 90일이며, 고정 월보험료는 3,141원이다. 1,000계약 기준 특약 NPV는 약 3,038.8만 원이다. 기존 보험금 조정액은 낮음 약 22.4만 원, 기준 약 31.6만 원, 높음 약 44.2만 원이고, 결합 종합영향은 각각 약 3,061.2만 원, 3,070.4만 원, 3,083.0만 원이다.

기준 보유율에서 담보별 보험사 영향은 사망 약 +26.5만 원, 심근경색 약 +4.8만 원, 뇌졸중 약 +0.5만 원, 담낭절제술 약 -0.2만 원이다. 특약 없음의 기대 최초 시작자는 204.50명, 특약 있음은 208.10명으로 추가 시작자 `B`는 3.60명이다.

기존 시장 저확산→고확산 결과는 기준 보유율에서 약 +1,110.6만 원으로 별도 참고한다. 이 값을 특약 NPV에 더하지 않았으며, 특약 기여효과 `A→A+B` 약 +31.6만 원과 구분한다.

## 해석 한계

담보 보유와 사건위험은 독립으로 가정하고 기대보험금을 선형 합산한다. 한 계약자가 여러 담보를 보유할 수 있지만 담보 간 상관은 손실분포·요구자본 분석 항목이므로 이번 기대손익에는 반영하지 않는다. 보험료 자체의 추가 행동반응, 세금, 자본비용, 준비금, 투자손익 및 IFRS17 보험계약마진은 제외한다.
