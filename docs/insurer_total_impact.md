# 약제비 특약과 기존 보험금 변화의 보험사 포트폴리오 종합영향

이 분석은 WE GO FIT 약제비 특약의 기대손익 NPV와, 특약 때문에 추가로 위고비를 시작한 가입자에서 발생하는 기존 보험금 변화를 결합한다. 주결과는 19~74세·남녀 판매 포트폴리오이며, 기존 62세 결과는 **SELECT 유사 대표집단 참고분석**으로 별도 보존한다.

```text
보험사 종합영향 = 약제비 특약 NPV + 기존 보험금 조정액

기존 보험금 조정액
= -Σ(특약 있음 A+B 보험금 PV - 특약 없음 A 보험금 PV)
    × SELECT 유사 고위험군 비중
    × 담보 보유율
```

시장 저확산→고확산 효과는 시장 전체 확산 참고값이며 최종 특약 손익에 합산하지 않는다.

## 실행

```bash
python -m models.impact.insurer_total_impact
jupyter nbconvert --to notebook --execute --inplace notebooks/impact/05_위고비_보험사_종합영향.ipynb
```

## 포트폴리오 구성

- 판매 가입연령: 19~74세
- 19~69세: 10년형
- 70~74세: 5년형
- 남녀 별도 계산
- 최초 계약: 정규화 후 총 1,000건
- MVP 8개 상품 모두 계산

조정 전 가중치는 다음과 같다.

```text
연령·성별 국내 인구
× 위고비 적격 대리비율
× 적격자 중 비당뇨 비율
× 위고비 미사용 비율
× 가입선택계수
```

연령·성별 인구는 [KOSIS 행정구역(시군구)별/1세별 주민등록인구 DT_1B04006](https://kosis.kr/statisticsList/mass/mass_list.jsp?org_id=101&process=statHtml&tbl_id=DT_1B04006)의 2025년 12월 전국 자료를 사용했다. 저장소에 연령·성별 적격률이 없으므로 국민건강영양조사 2024 재집계의 전체 성인 적격 대리비율 14.0195%와 적격자 중 비당뇨 비율 66.2770%를 모든 셀에 동일하게 적용했다. 미사용 95%는 연구팀 가정이다. 이 세 비율은 모든 셀에 같으므로 정규화된 구성비에는 영향을 주지 않는다.

### 가입구성 시나리오

| 시나리오 | 19~49세 | 50~59세 | 60~74세 | 구분 |
|---|---:|---:|---:|---|
| 기준 구성 | 1.00 | 1.00 | 1.00 | 구성 규칙 |
| 젊은층 집중 | 1.25 | 1.00 | 0.75 | 민감도 가정 |
| 고령·고위험 집중 | 0.75 | 1.00 | 1.25 | 민감도 가정 |

각 시나리오는 최종 구성비 합계가 1이 되도록 다시 정규화한다. 선택계수는 관측값이 아니다.

기준 구성의 연령대별 비중은 19~29세 15.49%, 30~39세 16.87%, 40~49세 19.16%, 50~59세 21.81%, 60~69세 20.01%, 70~74세 6.67%다. 전체 남성은 50.62%, 여성은 49.38%다.

## 셀별 특약 손익

각 상품·연령·성별 셀에서 판매조회표의 해당 확정 보험료와 보험기간으로 공통 현금흐름 엔진을 실행한다. 셀별 특약 NPV를 계산한 뒤 포트폴리오 구성비로 가중한다. 표시용 가중평균 보험료를 산출하지만, 평균 보험료를 현금흐름 입력으로 사용하지 않는다.

대표 상품은 조제당 10만 원·통산 13회·대기기간 90일이다. 기준 구성에서 가중평균 월보험료는 3,151.27원이고, 특약 NPV는 최초 1,000계약당 30,043,629.80원이다.

## 기존 보험금 변화

기존 보험금은 전체 가입자에게 적용하지 않는다. 기존 국민건강영양조사 재집계의 SELECT 유사 비중 0.256753%를 45~74세 셀에 적용하고, SELECT 연령기준에 해당하지 않는 19~44세에는 0을 적용한다.

```text
셀별 기존 보험금 변화
= 가입자 수
× SELECT 유사 고위험군 비중
× 담보 보유율
× SELECT 유사 계약 1건당 A→A+B 보험금 변화
```

연령별 임상 사건률 자료가 없으므로 SELECT 전체 사건률을 5년형·10년형 안에서 공통 적용한다. 이는 연령별 정밀 추정이 아니다. 사망·심근경색·뇌졸중 감소는 보험사에 유리한 방향, 담낭절제술 증가는 불리한 방향으로 반영한다.

담보 보유율 시나리오는 기존 설정을 유지한다.

| 담보 | 낮음 | 기준 | 높음 |
|---|---:|---:|---:|
| 사망보장 | 15.0% | 21.4% | 30.6% |
| 심근경색 | 30.0% | 40.0% | 50.0% |
| 뇌졸중 | 30.0% | 40.0% | 50.0% |
| 담낭절제술 수술 | 20.0% | 25.0% | 40.0% |

## 주결과

기준 가입구성 × 기준 담보 보유율에서 대표 상품 결과는 다음과 같다.

| 항목 | 최초 1,000계약 |
|---|---:|
| 특약 NPV | 30,043,629.80원 |
| 사망보험금 조정 | +377.69원 |
| 심근경색 보험금 조정 | +67.79원 |
| 뇌졸중 보험금 조정 | +7.76원 |
| 담낭절제술 보험금 조정 | -3.13원 |
| 기존 보험금 조정액 | +450.11원 |
| 보험사 종합영향 | **+30,044,079.91원** |

기존 보험금 조정액이 작아진 이유는 SELECT 유사 사건위험을 전체 1,000명에 적용하지 않고, 포트폴리오 중 45~74세의 SELECT 유사 비중에만 적용했기 때문이다.

### 가입구성별 대표 상품

| 가입구성 | 가중평균 월보험료 | 특약 NPV | 기존 보험금 조정 | 종합영향 |
|---|---:|---:|---:|---:|
| 기준 | 3,151.27원 | 30,043,629.80원 | 450.11원 | 30,044,079.91원 |
| 젊은층 집중 | 3,148.08원 | 30,344,115.86원 | 397.03원 | 30,344,512.89원 |
| 고령·고위험 집중 | 3,154.88원 | 29,703,373.53원 | 510.22원 | 29,703,883.75원 |

젊은층 집중은 대표 상품의 특약 NPV를 높이고, 고령·고위험 집중은 낮춘다. 기존 보험금 조정액은 고령층 집중에서 커지지만 절대 규모가 작아 종합영향의 순서를 바꾸지 않는다.

기존 62세, 남성 72%·여성 28%, 10년, 49세 여성 확정 월보험료 3,141원을 사용한 결과는 변경하지 않았다.

## 해석 한계

이 포트폴리오는 실제 특정 보험사의 판매구성이 아니다. 적격률·비당뇨 비율의 연령·성별 차이, 실제 가입선택, 연령별 SELECT 사건률, 담보 보유와 사건위험의 상관을 반영하지 못했다. 보험료 자체의 행동반응, 세금, 자본비용, 준비금, 투자손익과 IFRS17 보험계약마진도 제외한 연구용 기대손익 NPV다.
