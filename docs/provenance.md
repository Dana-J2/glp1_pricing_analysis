# 자료와 코드 출처
- 시작률: 해인 제출 `wegovy_start_rate_v4.zip`. 민서의 model과 해인의 6개 시나리오 실행부를 분리·경로 수정. 계산식은 유지.
- 집계 인구: 제출물의 nondiabetic_population.json. 국민건강영양조사 기반 팀 집계이며 원시 개인자료는 포함하지 않음.
- 치료: 성환 제출 `치료 지속·중단·재개 모형 전체 파일.zip`의 코드에서 중단을 약제 보유기간 종료일에 배치하고 일별 중단확률에 감소율 적용한 v1.1.
- 사망률: 기존 입력 엑셀의 JSON 스냅샷 outputs/input_v01/input_data.json에서 이관. 보험개발원 공개 참조순보험요율 예시와 팀 로그선형 보간값. 완전한 공식 경험생명표 원본이 아님.
- 계약 설정: 49세 여성·1,000명·사망력 배수 1·해지 0은 연결 검증용 가정. 실제 비만 가입자 위험으로 검증된 수치가 아님.
- reports는 버전 확인용 요약. 일별 결과는 실행으로 재생성.
- 치료 지속·재개 민감도 참조값: 성환 제출 `지속·재개 민감도 분석.zip`(SHA-256 `c6013d6e62ed9042af97ed5b68067e5ad32c7bf1cb49d836fb0b689ead372064`)의 원정밀도 결과. 현행 통합은 동봉 재가중 스크립트를 복사하지 않고 공통 엔진으로 13개 치료 경로를 재실행한다.
- 원본 제출물의 로컬 절대경로·캐시·중복 결과는 저장하지 않음.
