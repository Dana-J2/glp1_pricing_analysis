# 지급액·지급한도 9개 상품조건 비교

## 범위와 순서

지급액 10만·15만·20만원과 통산 지급한도 6·13·26회를 조합한 9개 설계를 비교한다. 대기기간은 90일, 소비자 체감 계획기간 `decision_horizon_units`는 13으로 고정한다. 목표이익률 10%가 주분석이고 5%를 함께 제시한다.

각 설계는 다음 순서를 독립적으로 수행한다.

```text
상품조건을 시작률 모형과 급부 모형에 함께 적용
→ 6개 시작률 시나리오를 해당 조건으로 새로 생성
→ base 시작률·기준 치료 행태로 보험료 산출
→ 원 단위 올림 보험료 고정
→ 시작률 6개 또는 치료 행태 13개를 별도로 평가
```

기준 상품의 시작률 CSV나 보험료를 다른 설계에 재사용하지 않는다. 13회와 26회는 계획기간 13과 90일 대기 때문에 같은 시작률이 나올 수 있지만, 현금흐름에서는 각 지급한도를 적용한다. 시작률과 치료 행태의 6×13 교차 스트레스는 실행하지 않는다.

## 수급자와 결과 분모

고유 수급자는 지급횟수 0 상태에서 최초 적격 지급을 받은 계약을 한 번만 집계한다. 시작자와 별도 지표이며 시작자 수로 대체하지 않는다.

- 1년·10년 시작자 비율: 최초 1,000계약 대비 최초 치료 시작자.
- 수급자 비율: 최초 1,000계약 대비 1회 이상 지급받은 고유 계약.
- 한도 소진 비율: 최초 1,000계약 대비 한도 소진 계약.
- 기대 급부·지급 횟수: 최초 계약 1건당.
- 스트레스 현가: 최초 계약 1,000건 기준.

## 실행

가격·혜택 표만 먼저 계산한다.

```bash
python -m models.rider.product_comparison --stage pricing
```

가격 단계가 정상이면 전체 분리 스트레스를 계산한다.

```bash
python -m models.rider.product_comparison --stage full
```

설정은 `config/product_comparison.json`, 결과는 `outputs/product_comparison/`에 저장된다.

- `design_pricing_benefit_comparison.csv`: 9개 설계×5%·10% 가격과 보장 지표.
- `start_rate_stress_108_results.csv`: 설계별로 다시 생성한 시작률 6개 수지.
- `treatment_stress_234_results.csv`: 설계 base 시작률 고정·치료 행태 13개 수지.
- `stress_detail_342_results.csv`: 두 분석군의 공통 형식 상세표.
- `decision_summary.csv`: 보험료·보장·주요 스트레스·분석군 최저 손익.
- `validation.json`: 회귀값, 상품조건 일치, 고정 보험료, 수급자 계층, 손익식 검증.

두 분석군의 기준 행은 같은 기준 경험을 중복 표시하며 결과 열에 이를 명시한다. `response_high` 손익의 양수 여부는 참고값일 뿐 판매 가능성이나 최적 상품을 판정하지 않는다. 시나리오에 발생확률을 부여하지 않았으므로 양수 손익 시나리오의 비중을 흑자 확률로 해석하지 않는다.

## 한계

시작률 및 치료 행태는 연구용 가정이며, 보험료 자체의 행동 반응·세금·자본비용·별도 투자손익은 반영하지 않았다. 시작률과 치료 행태 스트레스는 개별 적용했다.
